1. The Problem: Autonomous Rival Snakes in 2D Space

Creating an AI rival for a grid-based arcade game like Snake is deceptively challenging. In chess or turn-based strategy, an algorithm has time to analyze multiple future plies. In a real-time 60FPS browser canvas game, an AI rival must decide its next move within milliseconds while accounting for three constantly shifting constraints:

  • Dynamic Obstacles: The player's body and the bot's own expanding tail constantly change which grid cells are impassable.
  • Moving Objectives: Food spawns dynamically across open tiles and can be snatched by the human player at any second.
  • Self-Trapping Hazards: Eating food increases snake length, meaning a path that was safe at step 1 may cause self-entrapment by step 10 if the snake coils into a cul-de-sac.

To solve these challenges in Modern Snake, we developed an autonomous AI bot powered by a hybrid architecture: A* Pathfinding for optimal food routing, combined with a Flood-Fill Safety Evaluation and an Infinite Tail-Tracking Loop.

2. Understanding the A* Heuristic Formula: f(n) = g(n) + h(n)

The A* search algorithm evaluates adjacent grid nodes using a combined cost function:

f(n) = g(n) + h(n)
• g(n): The exact movement cost from the starting tile (the AI bot's head) to the current tile n.
• h(n): The heuristic estimated cost from tile n to the goal (food item coordinates).
• f(n): The total estimated cost of the cheapest path through node n.

Because movement in Snake is strictly orthogonal (up, down, left, right), the optimal heuristic is the Manhattan Distance:

function manhattanDistance(posA, posB) {
    return Math.abs(posA.x - posB.x) + Math.abs(posA.y - posB.y);
}

3. Complete JavaScript A* Pathfinder Implementation

Below is the core architecture utilized in the Modern Snake bot controller, using an open list (candidate nodes) and closed set (visited coordinates):

export class AStarPathfinder {
    constructor(gridWidth, gridHeight) {
        this.width = gridWidth;
        this.height = gridHeight;
    }

    findPath(start, goal, obstacles) {
        const openSet = [this.createNode(start.x, start.y, 0, this.heuristic(start, goal), null)];
        const closedSet = new Uint8Array(this.width * this.height);

        // Mark existing snake bodies and walls as obstacles
        for (const obs of obstacles) {
            closedSet[obs.y * this.width + obs.x] = 1;
        }

        while (openSet.length > 0) {
            // Pick node with lowest f cost
            let lowestIdx = 0;
            for (let i = 1; i < openSet.length; i++) {
                if (openSet[i].f < openSet[lowestIdx].f) lowestIdx = i;
            }
            const current = openSet.splice(lowestIdx, 1)[0];

            // Reached goal
            if (current.x === goal.x && current.y === goal.y) {
                return this.reconstructPath(current);
            }

            closedSet[current.y * this.width + current.x] = 1;

            // Inspect 4 orthogonal neighbors
            const neighbors = [
                { x: current.x, y: current.y - 1 },
                { x: current.x, y: current.y + 1 },
                { x: current.x - 1, y: current.y },
                { x: current.x + 1, y: current.y }
            ];

            for (const neighbor of neighbors) {
                if (neighbor.x < 0 || neighbor.x >= this.width || neighbor.y < 0 || neighbor.y >= this.height) continue;
                if (closedSet[neighbor.y * this.width + neighbor.x]) continue;

                const gScore = current.g + 1;
                const hScore = this.heuristic(neighbor, goal);
                const neighborNode = this.createNode(neighbor.x, neighbor.y, gScore, hScore, current);

                const existing = openSet.find(n => n.x === neighbor.x && n.y === neighbor.y);
                if (!existing) {
                    openSet.push(neighborNode);
                } else if (gScore < existing.g) {
                    existing.g = gScore;
                    existing.f = gScore + existing.h;
                    existing.parent = current;
                }
            }
        }
        return []; // No direct path to food found
    }

    heuristic(a, b) {
        return Math.abs(a.x - b.x) + Math.abs(a.y - b.y);
    }

    createNode(x, y, g, h, parent) {
        return { x, y, g, h, f: g + h, parent };
    }

    reconstructPath(endNode) {
        const path = [];
        let curr = endNode;
        while (curr.parent) {
            path.unshift({ x: curr.x, y: curr.y });
            curr = curr.parent;
        }
        return path;
    }
}

4. The Flood-Fill Trap Prevention Algorithm

Pure A* has a fatal flaw in Snake: blind greed. If an apple appears inside a narrow 'U'-shaped pocket formed by the snake's own coiled body, A* will gleefully navigate into the pocket, consume the apple, and instantly die because it trapped itself with nowhere to turn.

To eliminate suicidal path selection, the bot simulates taking the proposed path in virtual memory, and immediately performs a Breadth-First Flood-Fill from the new head position:

Safety Condition Check Formula Bot Action
Safe Corridor Reachable Space > Snake Length + 5 Execute A* shortest path to food
Constrained Pocket Reachable Space ≤ Snake Length Reject A* path; switch to longest safe survival path
Zero Open Food No valid unblocked path to apple Activate Tail-Tracking Loop

5. The Infinite Tail-Tracking Survival Loop

What should an AI bot do when every food item on the board is temporarily blocked by obstacles or player interference?

The solution is Tail Following. Because a snake's tail tip moves forward by one tile every time the head moves forward, the tile currently occupied by the tail tip is guaranteed to become free on the very next tick. By targeting its own tail with A*, the snake enters an orbit that can survive indefinitely until the playing field opens up.

6. 60FPS Zero-Allocation Memory Optimization

In web browsers, executing A* calculations 60 times per second can trigger heavy Garbage Collection (GC) pauses if new arrays and node objects are instantiated inside the game loop. Modern Snake achieves locked 60FPS by implementing three core optimizations:

  1. Flat TypedArrays: Replacing 2D multi-dimensional arrays with a single 1D Uint8Array(width * height) for instant O(1) closed-set lookups.
  2. Node Object Pooling: Pre-allocating a fixed pool of 500 node objects at initialization and reusing them across frames.
  3. Early Exit Pruning: Capping maximum path exploration iterations at 350 nodes, preventing frame drops even on complex 40x40 grid sizes.

7. Frequently Asked Questions

Can human players beat the A* AI rival snake?

Yes! While the AI calculates optimal paths, human players can use territorial space-cutting maneuvers (Hamiltonian coiling) to trap the AI bot against perimeter walls or cut off its tail-following escape route.

Does the AI rival cheat by looking through walls?

No. The AI rival operates under the exact same grid rules, boundary collision constraints, and speed parameters as the human player.

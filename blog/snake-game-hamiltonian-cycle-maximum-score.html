Snake Game Strategy: Hamiltonian Cycle & Maximum Score Explained

The strategy that guarantees you fill the entire board without trapping yourself.

MS
Modern Snake Game
Published 2026-11-19

The Problem: Why Snake Traps Itself

In Snake, every food item grows the snake by one cell. The longer the snake, the less free space remains, and a careless path can wall the head in with no escape. The maximum score equals filling every cell of the grid, leaving only the space the snake itself occupies.

What Is a Hamiltonian Cycle?

A Hamiltonian cycle is a path that visits every cell of the grid exactly once and then returns to its starting cell. If the snake always follows this cycle, it can never trap itself: there is always a route forward that covers every remaining cell.

How It Guarantees the Maximum Score

Because the cycle covers every cell, the snake can eat food in the order it appears along the cycle. Each food pickup extends the body by one cell, but the body simply follows the same cycle behind the head. When the snake finally occupies the whole board, it has achieved the maximum score.

Building the Cycle (Serpentine Pattern)

The simplest construction is a serpentine sweep: move right across a row, step down one cell, move left across the next row, step down, and repeat. On an even-width grid this forms a closed loop that touches every cell.

// Serpentine Hamiltonian cycle on an even-width grid
function buildCycle(cols, rows) {
  const path = [];
  for (let r = 0; r < rows; r++) {
    if (r % 2 === 0) {
      for (let c = 0; c < cols; c++) path.push([c, r]);
    } else {
      for (let c = cols - 1; c >= 0; c--) path.push([c, r]);
    }
  }
  // close the loop back to start
  path.push(path[0]);
  return path;
}

Shortcuts: Chasing Food Faster

Always following the full cycle is safe but slow. A smarter AI takes shortcuts: if food lies ahead on the cycle and the shortcut does not create a self-trap, jump to it. The key safety check is a flood-fill: ensure the head can still reach the tail after the move.

Practical Tips for Human Players

  • Keep the snake along the outer wall and spiral inward.
  • Avoid cutting across the middle until late in the game.
  • When the board is nearly full, slow down and plan two moves ahead.
  • On mobile, use swipe controls and keep your thumb anchored.

Common Mistakes

  • Rushing the head into a corner with no exit.
  • Creating a narrow tunnel the body cannot follow.
  • Ignoring the tail: it is your escape route.

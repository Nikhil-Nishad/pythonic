Snake Game History: From Nokia 6110 to Modern Web

When did the snake game come out? From the 1976 arcade Blockade to the Nokia 6110 and today's modern web snake games.

MS
Modern Snake Game
Published 2026-11-03

1976: Blockade, the First Snake

The snake concept debuted in 1976 as Blockade, an arcade game where players grew a line by eating dots without crashing into walls or themselves.

1980s–1990s: Home Computer Era

Snake variants spread to home computers and consoles, refining the core loop of eating, growing and avoiding collisions.

1997: Nokia 6110 Makes Snake Famous

Taneli Armanto's Snake shipped pre-installed on the Nokia 6110 in 1997, turning snake into a global cultural icon and one of the most played games ever.

2000s–2010s: Web and Mobile Boom

Flash and early HTML games brought snake to browsers, while smartphones introduced touch controls and new mechanics like slither.io's multiplayer.

2020s: Modern Web Snake

Today's modern snake games use HTML5 Canvas, PWA offline support, AI rivals and leaderboards — delivering 60 FPS, ad-free experiences in any browser.

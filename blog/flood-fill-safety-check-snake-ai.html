Flood Fill Safety Checks: Preventing Trap Trajectories in Snake AI

Why naive A* pathfinding causes autonomous Snake bots to suicide into enclosed coils, and how integrating Breadth-First Flood Fill and Voronoi territory checks creates unbeatable survival AI.

1. Why Naive A* Pathfinding Fails in Snake

A* pathfinding is mathematically proven to find the shortest path between two points on a grid. In video games like RPGs and RTS titles, this is exactly what you want. But in Snake, the shortest path is often suicidal.

Consider this common scenario:

#### WALL ####
# [H]========# (Snake body forming a tight U-turn coil)
# | (Food) #
# +========+# (Enclosed pocket)
##############

A standard A* algorithm sees a short 3-tile path directly to the food. It moves the snake's head into the pocket, consumes the food, and immediately crashes into its own body because there is no exit path remaining. The snake trapped itself in its own tail.

2. The Reachable Area Flood-Fill Algorithm

To prevent self-entrapment, the AI must evaluate the consequence of taking the proposed path before executing the move. It does this by running a virtual Flood Fill (Breadth-First Search).

The safety invariant is simple:

// Safety Invariant Condition
ReachableOpenTiles(AfterEating) >= CurrentSnakeLength + SafetyMargin

If the connected open space accessible from the destination cell is less than the snake's length, the space is a dead-end chamber that will choke the snake as it grows. The bot rejects the shortest path and switches to defensive survival maneuvers.

3. Production JavaScript Implementation of Flood Fill

Here is an optimized, flat-array flood fill implementation designed for low memory allocation:

export class SafetyEvaluator {
    constructor(gridSize) {
        this.gridSize = gridSize;
        this.totalCells = gridSize * gridSize;
        // Flat boolean typed array for visited markers (zero heap allocation)
        this.visited = new Uint8Array(this.totalCells);
        this.queue = new Int16Array(this.totalCells);
    }

    getReachableArea(startPos, obstacles, simulatedSnake) {
        this.visited.fill(0);
        let head = 0;
        let tail = 0;

        // Mark obstacles and current snake body as impassable
        for (let i = 0; i < simulatedSnake.length; i++) {
            const seg = simulatedSnake[i];
            this.visited[seg.y * this.gridSize + seg.x] = 1;
        }
        for (let i = 0; i < obstacles.length; i++) {
            const obs = obstacles[i];
            this.visited[obs.y * this.gridSize + obs.x] = 1;
        }

        const startIndex = startPos.y * this.gridSize + startPos.x;
        this.visited[startIndex] = 1;
        this.queue[tail++] = startIndex;

        let reachableCount = 0;

        while (head < tail) {
            const index = this.queue[head++];
            reachableCount++;

            const cx = index % this.gridSize;
            const cy = Math.floor(index / this.gridSize);

            // Explore 4-way orthogonal neighbors
            const neighbors = [
                { x: cx, y: cy - 1 },
                { x: cx, y: cy + 1 },
                { x: cx - 1, y: cy },
                { x: cx + 1, y: cy }
            ];

            for (let i = 0; i < 4; i++) {
                const nx = neighbors[i].x;
                const ny = neighbors[i].y;

                if (nx >= 0 && nx < this.gridSize && ny >= 0 && ny < this.gridSize) {
                    const nIndex = ny * this.gridSize + nx;
                    if (this.visited[nIndex] === 0) {
                        this.visited[nIndex] = 1;
                        this.queue[tail++] = nIndex;
                    }
                }
            }
        }

        return reachableCount;
    }
}

4. The Tail-Chasing Fallback Routine

When the food is deemed dangerous by the flood-fill safety check, what should the bot do instead? It cannot simply sit still.

The optimal fallback is Tail Chasing. Because the snake's tail vacates its position on every tick (provided it didn't eat food that turn), the tail tile is guaranteed to open up. By aiming for its own tail using A*, the bot forms an orbiting circle, stalling until the food becomes safe to consume.

// AI Decision Hierarchy
function chooseNextMove(bot, food, obstacles) {
    const pathToFood = astar(bot.head, food, bot.body, obstacles);
    
    if (pathToFood) {
        const simulatedSnake = simulatePath(bot.body, pathToFood);
        const freeSpace = safetyEvaluator.getReachableArea(food, obstacles, simulatedSnake);

        if (freeSpace > bot.body.length * 1.2) {
            return pathToFood[0]; // Safe path to food!
        }
    }

    // Unsafe path: follow tail to circulate safely
    const pathToTail = astar(bot.head, bot.tail, bot.body.slice(0, -1), obstacles);
    if (pathToTail) {
        return pathToTail[0];
    }

    // Emergency longest-path open neighbor
    return findLongestOpenNeighbor(bot.head, bot.body, obstacles);
}

5. Voronoi Space Partitioning in AI Rival Battles

In our game's AI Rival Mode, two snakes compete on the same board for the same food. In competitive multi-agent environments, flood fill generalizes into Voronoi Space Partitioning.

By executing a simultaneous two-source BFS from both the player's head and the bot's head, we calculate the number of grid tiles closer to the bot than to the player. The bot prioritizes moves that cut off the player's territory while maximizing its own safe operational room.

Frequently Asked Questions

How does flood fill performance scale on large grids?

Because our implementation uses pre-allocated flat TypedArrays (Uint8Array and Int16Array) instead of instantiating array objects or nodes on the heap, a complete 20x20 flood fill finishes in less than 0.05 milliseconds on mobile browsers.

Why does the tail cell have to be excluded as an obstacle when pathfinding?

Because on the next step the snake moves forward, the tail segment vacates that cell, making it a valid open tile to step into. Excluding the tail segment allows circular orbits without false collision triggers.

Can flood fill guarantee the snake will never die?

On small grids with high body length (>80% board saturation), only a full Hamiltonian Cycle can mathematically guarantee survival without trapping. Flood fill provides near-optimal heuristic safety up to 70% board saturation.
